# Dataset

Data materials are shared separately through OSF.

- DOI: [10.17605/OSF.IO/YQ9TZ](https://doi.org/10.17605/OSF.IO/YQ9TZ)

Place the downloaded OSF data package in this folder, or update the path
configuration cells in each notebook to point to the downloaded data location.

This GitHub repository intentionally does not store data files, generated
outputs, model checkpoints, or figures. Exact file names should follow the
OSF data package.
